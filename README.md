# Afdeling 55 Strandhusene - Digital Opslagstavle

Dette repository indeholder kildekoden til den digitale opslagstavle for **Afdeling 55 Strandhusene**.

## Filer i projektet:
- `index.html` - Selve applikationen og brugerfladen.
- `manifest.json` - PWA-konfiguration til installering på Android/iOS.
- `README.md` - Denne vejledning.

## Hosting på GitHub Pages:
1. Opret et gratis GitHub repository og upload disse filer.
2. Gå til **Settings > Pages** i dit repository.
3. Vælg `main` branch og gem.
4. Appen er nu live på nettet.

## Bestyrelsesadgang:
- Adgangskoden til at skifte til bestyrelsesvisning samt oprette og slette opslag er: `!2026-strandhusene`
