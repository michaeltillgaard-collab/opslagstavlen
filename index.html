Opsætning af Opslagstavlen på GitHub & Android

Følg denne enkle guide for at lægge appen online gratis og få den ned på beboernes telefoner.

1

Upload koden til GitHub (Gratis hosting)

Opret et gratis GitHub-repository kaldet f.eks. strandhusene-opslag.

    Upload denne index.html fil. Gå til Settings > Pages i dit repository. Vælg Branch: main og klik Save. Din opslagstavle er nu live på nettet!
2

Push-meddelelser & Firebase Integration

Denne app bruger en lokal simulator til at vise notifikationer på skærmen. Til rigtige Android push-notifikationer når appen er lukket:

1. Opret et gratis projekt på Firebase Console.

2. Aktivér Firebase Cloud Messaging (FCM).

3. Erstat simuleringsfunktionen i JS med Firebase Web Push SDK nøglen.

3

Lav appen om til en installerbar Android App (.apk)

I kan nemt pakke denne webapp som en rigtig Android-app:

    Brug PWABuilder.com (et gratis Microsoft-værktøj). Indtast webadressen til jeres GitHub Page. Download den færdige .apk fil og send den til beboerne, eller læg den i Google Play Store.
